Mailing List Backups

A private administration tool for the Creative Attribution mailing-list server.

The tool saves encrypted database and uploaded-media backups to the administrator's Google Drive account each day. These backups support recovery of subscriber records, list memberships, subscription preferences, and mailing-list content after a server failure.

This is not a public sign-up service. Google Drive access is authorized by the administrator and limited to files created or explicitly opened with this app.
