Mailing List Backups

Privacy and Google Drive data use

Updated 12 October 2026. This notice describes the private Google Drive backup tool for the Creative Attribution mailing-list server.

Purpose and permissions

The tool uses the Google Drive API solely to create, verify, retrieve, and retire disaster-recovery backups in the administrator's Drive account. It requests the drive.file permission, covering files created or explicitly opened with this app. It does not request access to all existing Drive files, Gmail, Google Contacts, or Google Photos.

Information handled

Backup files contain a database export and uploaded media from the mailing-list server. The database includes subscriber contact details, list memberships, subscription and unsubscribe status, campaigns, templates, settings, and other records held by the server. The tool also handles backup file identifiers, sizes, timestamps, and authorization tokens needed to use Drive.

Storage and use

Backup contents and filenames are encrypted on the server before upload using rclone crypt. Google Drive stores the encrypted files and associated storage metadata. Access is intended for the mailing-list administrator; the tool does not publish or share backups, sell their contents, use them for advertising, or use Google user data to train AI models.

OAuth tokens and the encryption configuration are stored privately on the administrator's computer and server. An administrator must retain a separate recovery copy of the encryption configuration to restore encrypted backups.

Retention and deletion

The automatic schedule is daily, retaining approximately 30 days of verified backups. Older backup files are moved to Drive's Trash only after a newer upload is verified. Trashed files continue to use storage until Google removes them or the administrator empties Trash. Existing backup copies remain until deleted; revoking access does not delete them.

Control and contact

The administrator can stop the server's backup job, remove its saved authorization, revoke the app through Google Account connections, or delete backup files in Drive. For questions or removal requests, contact the administrator using the support email shown on this app's Google consent screen.

The tool's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
